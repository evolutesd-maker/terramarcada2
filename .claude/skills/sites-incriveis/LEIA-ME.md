# Sites Incríveis — instalação em 1 minuto

Skill de Claude Code que transforma qualquer site numa experiência interativa
de rolagem. Criada por Enzo Barbatto (Sparo).

## Instalar

1. Baixe e extraia esta pasta (`sites-incriveis/`).
2. Copie a pasta inteira para dentro do seu projeto, em:
   - `.claude/skills/sites-incriveis/` (Claude Code)
   - e também `.agents/skills/sites-incriveis/` se você usa o Antigravity.
   (Se a pasta `.claude/skills/` não existir, crie.)

   💡 Quer a skill disponível em TODOS os seus projetos de uma vez?
   Copie para a pasta global do seu usuário:
   - Windows: `C:\Users\SEU-NOME\.claude\skills\sites-incriveis\`
   - Mac/Linux: `~/.claude/skills/sites-incriveis/`
3. Abra o Claude Code no projeto e digite `site` — a skill **sites-incriveis**
   aparece na lista. Pronto.

## Usar

Abra o Claude Code na pasta do seu site e peça, por exemplo:

> Usa a skill sites-incriveis pra refazer minha página. Mantém os textos, preços e
> links. Quero algo premium, que prenda a pessoa rolando até o final.

A skill vai te **entrevistar** antes de construir (7 perguntas) — responda com
calma, é isso que faz o seu site sair diferente de todos os outros. No final,
ela verifica o próprio trabalho tirando screenshots da página rolando.

## Precisa ter

- Claude Code instalado.
- Google Chrome (para a verificação automática).
- Node.js (o Claude avisa e instala o que faltar durante o processo).
